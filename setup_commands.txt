=== คำสั่งสำหรับเริ่มต้นใช้งาน (Setup Commands) ===

1. ลง Library ที่จำเป็น (สำหรับเครื่องใหม่ หรือครั้งแรก):
   npm install

2. สร้าง Database และ User เริ่มต้น (สำหรับครั้งแรก):
   npm run init

   *หมายเหตุ: คำสั่งนี้จะสร้าง Folder 'data' และไฟล์ Database ให้โดยอัตโนมัติ
   *User เริ่มต้น: admin / password123
   *User ทั่วไป: user / user123

3. รัน Server:
   npm start

   *เปิดเว็บที่: http://localhost:3000
